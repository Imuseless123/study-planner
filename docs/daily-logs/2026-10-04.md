| 9 | `feedback` | Đánh giá lịch trình (1-5 sao + nhận xét) |

**Đặc điểm kỹ thuật:**
- ✅ UUID primary keys, có `server_default=gen_random_uuid()`
- ✅ Foreign keys với `ON DELETE CASCADE` (10 FK)
- ✅ Check constraints (11 constraints): difficulty/priority/focus/quality trong 1-5, `required_hours > 0`, `duration > 0`, `wake_time > sleep_time`, `rating BETWEEN 1 AND 5`, `risk_score 0-100`
- ✅ Unique constraints: `username`, `email`, `(user_id, log_date)` cho mood
- ✅ 11 indexes cho query performance

**Vấn đề gặp phải và fix:**

| Vấn đề | Nguyên nhân | Fix |
|--------|-------------|-----|
| Alembic autogenerate không tạo index | ORM models không khai báo `Index()` | Thêm thủ công 11 `op.create_index()` vào migration + 11 `op.drop_index()` vào downgrade |
| SQL INSERT thuần fail UUID null | ORM dùng Python-level default, không áp dụng cho SQL thuần | Thêm `server_default=sa.text('gen_random_uuid()')` + `CREATE EXTENSION pgcrypto` |
| Mojibake tiếng Việt trong terminal | Locale mismatch giữa file SQL và terminal | Dùng comment tiếng Anh trong SQL test để tránh |

### 2.7. Vấn đề khi chạy

**Triệu chứng:** Sau `docker compose restart backend`, log rỗng, curl trả về rỗng, `$TOKEN` length = 0.

**Nguyên nhân:** Container backend **chưa từng được tạo** ở lần đầu. Lệnh `docker compose restart` chỉ hoạt động với container đã tồn tại, không tạo mới.

**Fix:** `docker compose up -d backend` để tạo và chạy container ở chế độ detached.

**Bài học:** Với service mới, luôn dùng `up -d` thay vì `restart`.

## 5. Bài học kinh nghiệm

### 5.1. Về Docker Compose
- Không cần khai báo custom network cho setup đơn giản — default network đủ dùng
- `docker compose config` để verify syntax trước khi `up`
- `docker compose up -d` để tạo mới, `docker compose restart` chỉ restart container đã có

### 5.2. Về Alembic
- **Autogenerate không hoàn hảo:** phải review file migration trước khi `upgrade head`
- Index nên khai báo tường minh trong ORM models (`__table_args__ = (Index(...),)`)
- Với UUID PK, cần cả Python default (`default=gen_uuid`) và SQL default (`server_default=gen_random_uuid()`)

### 5.3. Về terminal
- Dùng `docker compose exec -T` (flag `-T` = no TTY) khi pipe heredoc
- Comment SQL dùng tiếng Anh để tránh mojibake khi locale mismatch
- Biến shell (`$TOKEN`) không persist giữa các tab terminal — phải export lại

### 5.4. Về FastAPI
- `HTTPBearer` trả 403 khi thiếu token, không phải 401 (cần custom scheme nếu muốn chuẩn OAuth2)
- Pydantic v2 dùng `model_config = ConfigDict(...)` thay vì `class Config`
- `EmailStr` cần `email-validator` package
